## Index Of Studies

![](public/shared/images/banner.png)

A collection of ideas and experimental works exploring motion, interaction, and visual systems.

[Demo](https://studies.ibrahimraimi.xyz)

### Installation, run the following commands:

```bash
bun install

bun dev
```

### If you do not have bun installed, delete the `bun.lock` file and install via npm,

```bash
npm install

npm run dev
```
